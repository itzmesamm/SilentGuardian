# SilentGuardian
SilentGuardian - Edge AI based autonomous emergency detection system using multimodal sensor fusion.
## Current Progress

The CNN-based audio distress detection module has been implemented.

Completed components:
- Audio preprocessing using MFCC features
- CNN model for distress sound classification
- Model training and evaluation
- Confusion matrix and classification report
- TensorFlow Lite conversion for mobile deployment

Future work:
- RNN-based motion detection using accelerometer data
- GPS-based location tracking
- Integration of all modules into the SilentGuardian mobile system
